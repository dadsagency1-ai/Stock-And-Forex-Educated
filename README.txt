# Stock and Forex Market — 2-Page Vercel Landing Page

## Files
- `index.html` — main landing page
- `page2.html` — education / insights / risk page
- `styles.css` — responsive premium styling
- `config.js` — Telegram link placeholder
- `assets/profile.png` — uploaded artwork

## Add your Telegram link
Open `config.js` and replace:
`https://t.me/YOUR_TELEGRAM_LINK`
with your real Telegram channel/group URL.

## Deploy on Vercel
1. Create a new Vercel project.
2. Upload/extract these files into the project.
3. Deploy as a static site.
4. Test both pages and the Telegram button before running ads.

## Compliance-oriented copy
The page avoids guaranteed profit claims, fixed-return promises, fake urgency, or personalized investment recommendations. It includes risk disclosure and educational framing. Review the final page and any ad creative against the current advertising policies that apply to your campaign.
